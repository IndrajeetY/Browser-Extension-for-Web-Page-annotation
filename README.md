**Web Text Editor & Highlighter**
  Web Text Editor & Highlighter is a lightweight Chrome extension that allows you to edit, highlight, and annotate text directly on webpages for your personal use.
  When you select text, a smart floating toolbar appears near your selection, giving you quick access to powerful editing tools — similar to professional web annotation extensions.

**Features**
  
  Bold text
  Highlight text
  Strike through text
  Floating toolbar near selection
  Per-edit Undo & Redo
  Delete individual edits
  Re-select and modify any previous edit
  Works on most standard websites (blogs, articles, documentation)

**Privacy & Safety**

  All edits are applied locally in your browser
  No data is sent to any server
  No website content is permanently modified
  Other users never see your changes

**Use Cases**

  Studying and learning from articles
  Research and reading notes
  Highlighting important information
  Personal annotations on live webpages

**Limitations**

  Does not work on Chrome internal pages (chrome://)
  Some web apps (Google Docs, Gmail) restrict text manipulation
  Changes reset on page reload unless persistence is enabled
